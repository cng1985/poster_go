# 验收记录

规范检查表不把本文当成全部通过。下面只记录这次实现里已经验证和明确没做的部分。

| 编号 | 结果 |
| --- | --- |
| A01 | 账号、模板、素材、海报、生成、分析按业务拆开。海报的增删改查和复制仍是一个作品业务。 |
| A02 | Controller 只绑定和输出。Resource 做规则。Repository 做数据库。生成和上传在事务外调用模型与磁盘。 |
| A03 | 公开业务方法使用 Request/Search 和 Response/PageResponse。下载图片是 HTTP 适配，不改变业务返回。 |
| A04 | 注册把账号和会话放在一个事务里。测试用触发器让会话插入失败，确认账号回滚。海报保存是带版本条件的一次更新。 |
| A05 | 生成记录和海报不是一个事务，文档写明了。没有跨模块库存类原子操作。 |
| A06 | Scope 来自会话。作品、素材、生成和分析都按 ActorID 过滤。他人的标识返回不存在。 |
| A07 | 创建拒绝客户端主键。透明度为 0 可以保存。版本冲突返回 10004。删除重放返回不存在。 |
| A08 | 海报排序只有白名单。分页非法值会报错，空列表是 `[]`。 |
| A09 | 三份配置在 `configs/`。测试覆盖了环境变量把布尔 `false` 和端口覆盖进去。 |
| A10 | 只验证了 SQLite。其他三种驱动会在迁移阶段拒绝启动。 |
| A11 | 健康检查、未知接口、错误方法和页面回退有 HTTP 测试。登录失败有内存限流。 |
| A12 | 三个脚本入口已提供。发布包在本环境只实际编译了当前 Linux 目标的开发运行，没有把 Windows 和 arm64 启动列为已验证。 |
| A13 | 没有做备份恢复演练。 |
| A14 | 没有缓存、队列、Outbox 和多租户。模型和本地文件是因为产品需要才加的。 |
| A15 | 没有另做一个无用的商品模块。作品版本、所有权隔离、空值和注册回滚对应该样板要验证的风险。 |

`go test ./...` 覆盖配置覆盖、注册回滚、登录吊销、海报版本和跨用户、外键、本地生成、低对比分析和图片魔数。`tests` 覆盖注册、模板分页、跨用户读取、未知接口、405 和 SPA/静态 404 的区分。
